# STATUS

Built 2026-10-31 by Asdale Dynamics, LLC.

## What was built

**free-fact-check-directory** — a hand-curated directory of free
fact-checking sources and tools, in two forms:

- `content/*.md` — the docs (markdown source, edited by hand):
  - `sources.md`: Snopes, PolitiFact, AP Fact Checks, Reuters Fact
    Check, FactCheck.org, plus official CDC, Census Bureau, and IRS
    pages, and a quick quote/claim checking method.
  - `tools.md`: reverse-image search routes (Google Lens, TinEye,
    Yandex Images, Bing Visual Search) with a full image-check
    procedure, and archive/cache lookups (Wayback Machine,
    archive.today), including the 2024 note that search-engine
    page caches are gone.
  - `checklists.md`: five universal frame questions plus topic
    checklists for health, money, and weather rumors.
  - `share-card.md`: plain-text group-chat card teaching
    verify-before-forward, with sharing tips.
- `site/` — the static HTML site generated by `build.py`:
  `index.html` (table of contents with per-page headings),
  `sources.html`, `tools.html`, `checklists.html`,
  `share-card.html`, and `assets/style.css`.
- `build.py` — stdlib-only build script (no dependencies): markdown
  renderer (headings, lists, checkboxes, tables, code, autolinked
  URLs), HTML templating, and validation of every generated page.
- `README.md`, `LICENSE` (MIT, Copyright (c) 2026 Asdale Dynamics, LLC).

Relationship to sibling projects: it is a *where-to-check* directory,
distinct from the how-detection-works guide (spot-fake-media-guide)
and the link-inspecting tool (link-safety-inspector-cli).

## How to run

```sh
python3 build.py          # build + validation, writes site/
python3 build.py --test   # same, plus content spot checks
```

Then open `site/index.html` in any browser. Python 3 only, no
installs. Regenerate after editing anything under `content/`.

## Known gaps

- Link liveness is checked structurally, not by network requests;
  hosts could change paths over time (retraining-free manual check
  applies before each release).
- archive.today has several entry domains (archive.today/.is/.li
  etc.); only archive.ph is listed to keep one stable link.
- The markdown renderer covers the subset used here (commonmark
  features like nested lists and definition lists are not needed
  and not implemented).
- No screenshots or svg assets; styling is intentionally minimal.
