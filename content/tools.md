# Verification Tools

Free tools for checking images and finding old copies of a page.
None of these require payment for basic use, and none of the routes
below involve affiliate or referral links.

## Reverse-image search routes

Reverse-image search answers one question: where else has this image
appeared before? An image that is really from a 2013 flood will show
that up immediately. Work through the routes in order — each engine
indexes different sites, so check more than one.

### Google Lens (images.google.com)

- **Link:** https://images.google.com
- **What it is:** Google's reverse image search. On a phone, tap the
  camera icon in the search box; on a desktop, click the camera icon
  (Lens) to paste an image URL or upload the file.
- **Use it for:** The fastest first check on any forwarded photo.
- **Free tier:** Entirely free, Google account not required.

### TinEye

- **Link:** https://tineye.com
- **What it is:** A dedicated reverse-image engine that sorts results
  by "oldest first," which helps you find the original use of an image.
- **Use it for:** Finding when and where an image first appeared.
- **Free tier:** Free for everyday searches, no account needed.

### Yandex Images

- **Link:** https://yandex.com/images/
- **What it is:** Yandex's visual image search, often better than
  Google at matching people and photos shared on non-English sites.
- **Use it for:** The second opinion when Google and TinEye find
  nothing.
- **Free tier:** Entirely free.

### Bing Visual Search

- **Link:** https://www.bing.com/visualsearch
- **What it is:** Microsoft's reverse image search, available by
  clicking the visual-search icon in the Bing search box.
- **Use it for:** Another independent index when other engines miss.
- **Free tier:** Entirely free, no account needed.

### How to run a full image check

1. Save the image (or take a screenshot of it) from the post.
2. Upload or paste it at images.google.com and read the top results.
3. Repeat on TinEye, sorted by oldest.
4. Repeat on Yandex Images.
5. Look for the **earliest** date the image appears, not the loudest
   one — the first sighting is what tells you where it really came from.

## Archive and cache lookups

Archives save snapshots of web pages. They answer a different question:
what did this page (used to) say — before it was edited or deleted?

### Wayback Machine (Internet Archive)

- **Link:** https://web.archive.org
- **What it is:** The classic web archive. Paste any URL to see saved
  snapshots going back up to decades.
- **Use it for:** Pages that were edited, deleted, or quoted
  selectively; citable "receipts" with fixed dates and URLs.
- **Free tier:** Entirely free, no account needed to read; a free
  account lets you save pages on demand.
- **Tip:** To save a page right now, use
  https://web.archive.org/save/ and paste the URL after it.

### archive.today

- **Link:** https://archive.ph
- **What it is:** An independent snapshot archive with alternate
  entry points such as archive.today and archive.is.
- **Use it for:** Pages the Wayback Machine did not capture, and
  pages that block bots.
- **Free tier:** Entirely free to read.

### Caching tips

- Many search engines removed their old page-cache feature in 2024,
  so when someone says "check the Google cache," use the Wayback
  Machine or archive.today instead — snapshots, not caches, are how
  this is done today.
- Browser "reader mode" and printer preview can also capture the
  current text of a page for your own records.

## When the tools disagree

- If one engine finds the original image and another does not, trust
  what the results actually show, not the count of engines.
- Screenshots are not sources. Someone can fake a screenshot of a
  fact-check site; click through to the real site before believing
  a screenshot of an article.
- Record what you did (which engines, what dates) so you can explain
  your conclusion if someone asks later.
